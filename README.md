# kip8-desktop — КИПиА (ПРОДАКШН) Desktop

Десктопная **боевая** сборка приложения «КИПиА — справочник инженера» на Electron.

## Назначение

Этот репозиторий содержит десктопную (Electron) сборку боевого приложения.
Мобильная PWA-версия живёт в [`kip8`](https://github.com/bloknett-design/kip8).
Тестовая десктоп-сборка — в [`kip8test-desktop`](https://github.com/bloknett-design/kip8test-desktop).

## Связи с kip8

- `index.html` **синхронизируется автоматически** из `kip8` при каждом его обновлении
  (GitHub Action `sync-to-desktop.yml` в репозитории kip8, секрет `DESKTOP_SYNC_TOKEN`).
- `sw.js`, `scripts/*.gs`, `tests/` — синхронизируются автоматически из `kip8`
  (контентные файлы для полного паритета тестов: 1433 теста); в Electron-сборку
  НЕ попадают (files в package.json: index.html/images/data/electron).
- `data/`, `images/` — статические копии из kip8 для офлайн-fallback
  (обновляются вручную при переносе/релизе).
- Приложение при запуске грузит живую страницу https://bloknett-design.github.io/kip8/
  (fallback — локальные файлы `app://` при отсутствии сети).
- `cleanCacheOnStartup` очищает SW/кэш при каждом запуске — пользователю достаточно
  перезапустить приложение, чтобы получить свежий контент (без переустановки).
- `electron-updater` проверяет GitHub Releases этого репозитория и предлагает
  обновление при выходе новой версии. С версии 2.1.8 — Windows-сборки двух
  разрядностей (x64 и ia32/Win32) + универсальный установщик; каждая разрядность
  обновляется своим файлом из общего `latest.yml`.

## Структура

```
kip8-desktop/
├── index.html              # Тот же код, что в kip8/index.html
│                           # (синхронизируется автоматически через GitHub Action)
├── electron/
│   └── main.js             # Точка входа Electron (REMOTE_APP_URL = kip8)
├── package.json            # electron-builder конфиг (appId com.bloknett.kipia)
├── package-lock.json
├── sw.js                  # Копия PWA service worker из kip8 (фикстура тестов;
│                           # в Electron-сборку НЕ попадает)
├── scripts/               # Apps Script .gs из kip8 (фикстуры тестов, 8 файлов;
│                           # сервер бэкенда НЕ задеплоен отсюда)
├── data/                   # Статическая копия данных (синхронизируется при релизе)
├── images/                 # Иконки, логотипы, иллюстрации
├── tests/                  # Тесты — байт-в-байт из kip8 (1433 passed / 0 failed)
└── .github/workflows/
    ├── build-desktop.yml       # Сборка под Windows/Linux/macOS + релиз на тег v*
    ├── build-legacy-win7.yml   # Легаси-сборка для Win7/8.1 (тег legacy-v*, Electron 22)
    └── ci.yml                  # Тесты при каждом пуше
```

## Сборка и релизы

При пуше тега `v*` (например `v2.1.8`) автоматически собираются:

- **Windows (универсальный)** — `KIPiA-Setup-2.1.8.exe` — один установщик для
  любой разрядности (сам определяет 64/32-бит и ставит нужную сборку)
- **Windows 64-бит** — `KIPiA-Setup-2.1.8-x64.exe` (64-бит, меньше размер)
- **Windows 32-бит (Win32)** — `KIPiA-Setup-2.1.8-ia32.exe` — отдельная сборка
  для 32-битных систем (старые ПК/ноутбуки с 32-битной Windows); начиная с 2.1.8
- **Linux** — `KIPiA-2.1.8.AppImage` + `KIPiA-2.1.8.deb`
- **macOS** — `KIPiA-2.1.8.dmg`

Все артефакты публикуются в [Releases](https://github.com/bloknett-design/kip8-desktop/releases).

### Как выбрать установщик Windows

- Не знаете разрядность — качайте универсальный `KIPiA-Setup-<версия>.exe`
  (работает везде; просто больше по размеру — содержит обе сборки).
- 64-битная Windows — `KIPiA-Setup-<версия>-x64.exe` (почти все современные ПК).
- 32-битная Windows (Win32) — `KIPiA-Setup-<версия>-ia32.exe`.
- Автообновление разрядностезависимое: установка проверяет общий `latest.yml`
  и скачивает файл своей разрядности (`-x64.exe` / `-ia32.exe`).
- **ВАЖНО: всем этим установщикам нужна Windows 10 или новее** (включая
  ia32 — разрядность ≠ старая ОС). Для Windows 7/8.1 — см. «Легаси-сборка
  для Windows 7/8.1» ниже: на Win7/8.1 запуск основного установщика даёт
  ошибку «KIPiA.exe не является приложением Win32» (PE-заголовок бинарников
  Electron 35 объявляет OS 10.00 — загрузчик старой ОС отклоняет образ).

## Легаси-сборка для Windows 7 / 8.1 (Task 354)

Для компьютеров, которые нельзя обновить до Windows 10, собирается отдельная
**легаси-линейка** установщиков на Electron 22.3.27 — последней версии Electron
с поддержкой Windows 7/8.1 (Chromium 108; PE-заголовок её бинарников объявляет
OS 5.01, поэтому загрузчик Win7/8.1 их принимает).

Файлы (релизы с тегом `legacy-v*`, помечены pre-release):

- `KIPiA-Setup-<версия>-win7-ia32.exe` — 32-битная Windows 7/8.1
- `KIPiA-Setup-<версия>-win7-x64.exe` — 64-битная Windows 7/8.1
- `KIPiA-Setup-<версия>-win7.exe` — универсальный (сам выберет разрядность)

Отличия от основной сборки:

- **Автообновление оболочки отключено** (флаг `kipiaWin7Legacy` в package.json:
  `electron/main.js` не проверяет обновления): основной канал `latest.yml`
  раздаёт сборки на Electron 35 — они бы «сломали» приложение на Win7.
  Содержимое справочника при этом обновляется автоматически — приложение
  по-прежнему грузит index.html с GitHub Pages (офлайн-fallback — локальные
  файлы).
- `electron-builder-legacy.yml` — отдельный конфиг (Electron 22.3.27,
  версия `<N>-lts`, артефакты `*-win7-*`, выход в `dist-legacy/`, без
  publish-канала).
- `.github/workflows/build-legacy-win7.yml` — сборка по тегу `legacy-v*`
  (windows-latest — rcedit без wine), ПЕ-верификация в CI (машина обязана
  быть 0x014c/0x8664 и объявлять PE OS 5.01 — страховка от «протечки»
  Win10-бинарников в легаси-линейку), релиз — prerelease только из `*.exe`.
- Windows XP и Vista не поддерживаются вовсе (Electron требует Win7 SP1+).
- Chromium 108 не получает обновлений безопасности — ставить только там,
  где обновление ОС невозможно.

## Когда нужен новый релиз (переустановка пользователями)

Только при изменениях в `electron/main.js` или `package.json` (логика окна,
автообновление, зависимости). Обновления `index.html` приходят пользователям
автоматически при перезапуске приложения — релиз не нужен.

## Локальный запуск

```bash
npm install
npm start        # electron .
```
